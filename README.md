# alta
Agents Learning to Act


Steps:

1. Clone repository
2. Create conda environment using environment file.
3. Do "pip install -e ." from within alta repository.
4. Clone stable-baselines, and do "pip install -e ." from within stable-baselines.
5. set CARLA_9_4_PATH environment variable to point to the directory containing CARLA binaries.
e.g. adding following line in .bashrc:
export CARLA_9_4_PATH=/zfsauton2/home/hiteshar/CARLA_0.9.6
